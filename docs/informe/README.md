# Informe final

`informe.tex` es la fuente del informe; `informe.pdf` es la versión que se entrega y que publica la página del proyecto.

Para regenerar el PDF desde esta carpeta:

```
tectonic informe.tex
```

`fig/componentes.png` es una captura de `docs/site/diagrams/componentes.svg` a doble resolución. Si cambia el SVG, hay que volver a generarla.
